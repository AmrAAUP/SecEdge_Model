# Edge-IIoTset dataset attribution and terms

The retained benchmark CSVs are subsets of **Edge-IIoTset**, created by Mohamed Amine Ferrag, Othmane Friha, Djallel Hamouda, Leandros Maglaras and Helge Janicke.

Citation: M. A. Ferrag et al., “Edge-IIoTset: A New Comprehensive Realistic Cyber Security Dataset of IoT and IIoT Applications for Centralized and Federated Learning,” *IEEE Access*, vol. 10, pp. 40281–40306, 2022, DOI [10.1109/ACCESS.2022.3165809](https://doi.org/10.1109/ACCESS.2022.3165809).

The [dataset author's primary metadata](https://www.kaggle.com/mohamedamineferrag/edgeiiotset-cyber-security-dataset-of-iot-iiot/metadata) identifies **CC BY-NC-SA 4.0**, grants academic research use and requests attribution. Its included creator Readme discusses commercial use by permission from the lead author. [License terms](https://creativecommons.org/licenses/by-nc-sa/4.0/) and [legal code](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.en) remain upstream terms; the repository's code license does not relicense dataset material.

The creator Readme also identifies the earlier preprint, DOI [10.36227/techrxiv.18857336.v1](https://doi.org/10.36227/techrxiv.18857336.v1). Dataset records include testbed addresses, timestamps and protocol/payload fields. No claim of newly collected operational network traffic is made.

Source checked on 8 October 2026. This notice describes the upstream record and retained research subsets; it is not a new permission grant or a claim that every third-party component shares the dataset license.
