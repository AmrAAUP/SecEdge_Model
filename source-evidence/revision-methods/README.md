# Revision methods and completed Pi donor study

This collection contains the scientific records needed to inspect the separate
revision-stage donor-sensitivity experiment. Start with the
[current evidence guide](../../docs/evidence-guide.md). The original thirteen-target
registration, calibration/draw bindings, rationale audit and original interventions
are in the [original-study collection](../original-study/).

## Design and inputs

`intervention/INTERVENTION_PROTOCOL_v2.json` fixes the checkpoint, scoring,
selection, seeds, exclusions and validity checks: 30 retained occurrences
representing 28 distinct inputs and five fixed Normal validation donors.
`benign_validation_donors.json` supplies the donor values and source identities;
`pi_sensitivity_payload_v2.json` and `pi_sensitivity_payload_v3.json` retain the
selected flow blocks and scoring inputs. The `retained_pi/` reconstructions
record all 150 candidate inputs and their decoded prompts; the original token
bundle is retained in [Pi startup](../pi-startup/).

## Completed execution and analysis

The complete merged event stream is `intervention/pi_sensitivity_results_v3.jsonl`.
It contains the 86-event original prefix followed by the continuation, including
1,430 single and 300 joint substitutions. `EXECUTION_CONTINUATION_v3.json`, the
planned/completed event ledgers and terminal/session receipts document completion
and the exact prefix hash. Execution v3 resumed the same strict full-reset
scientific protocol; it did not change the study or use prefix optimization.
The first prefix-byte count specified by the execution amendment reproduces the
original prefix SHA-256 directly from the merged stream.

`pi_sensitivity_analysis_plan_v3.json` and the saved summary, flow and intervention
analyses retain all comparisons, exclusions, flagged substitutions and uncertainty
calculations. The reporting clarification and independent completed-chain audit
record the interpretation of caches, elapsed time and input counts.

Source workers and analysis are retained unchanged in `intervention/source/`.
They contain the original workspace layout and assertions; portable reanalysis
requires an explicitly disclosed path adaptation in a separate copy. Preserve the
released inputs, source hashes and completed outputs. No source was executed or
model rerun to assemble this publication collection.

## Interpretation and integrity

Results are conditional on one checkpoint, 28 input groups and the fixed donor
panel. Substitution measures input sensitivity; the recorded checks do not prove
physical packet validity or causal network mechanisms.

This is a curated scientific subset of the earlier revision supplement. The
separate 407/150-rationale retrospective screen, dated missing-record search
checklists, archive administration and duplicated Pi workers are omitted. Original
study evidence is supplied in its own collection rather than replaced by a later
audit. Scientific members included here retain their original bytes; the
repository publication manifest covers their paths and hashes. Documentary dates
and matching hashes do not independently certify prospective chronology.
